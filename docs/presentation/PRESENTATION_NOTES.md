## 🚫 3. ทำไมตัวกรองดั้งเดิม (Classical LTI Filters) ถึงสอบตก? (The Proof)

### ปัญหาการซ้อนทับกันของสเปกตรัม (Spectral Overlap)
* ทั้งเสียงพูดจริง (Near-End Speech) และเสียงสะท้อน (Echo) ต่างก็เป็น **เสียงมนุษย์เหมือนกัน**
* พลังงานของทั้งคู่จึงแชร์ย่านความถี่เดียวกันเป๊ะ (ช่วง $100\text{ Hz} - 4,000\text{ Hz}$)

### การพิสูจน์ใน Notebook (Cell 6, 7, 8):
1. **Lowpass Filter (ตัดความถี่สูง):** เสียงก้องสูงหายไปจริง แต่เสียงคนพูดจะกลายเป็น **เสียงอู้อี้เหมือนคุยในโอ่ง** เพราะเสียงพยัญชนะความถี่สูงโดนทำลาย
2. **Bandstop / Notch Filter (ตัดเฉพาะย่าน):** เนื้อเสียงแหว่งและบิดเบี้ยว (Distortion) แต่เสียงก้องย่านอื่นก็ยังคงสะท้อนอยู่ดี
3. **บทสรุปเชิงทฤษฎี:** *"ตัวกรองคงที่ (Fixed Frequency-Selective Filters) ไม่สามารถแยกสัญญาณสองตัวที่แชร์ย่านความถี่เดียวกันออกจากกันได้"* ➔ **จึงเป็นเหตุผล 100% ว่าทำไมต้องใช้ Adaptive Filter (LMS / NLMS)!**

## 🔬 4. เกร็ดทางเทคนิค DSP สำคัญ (ตอบให้อาจารย์ทึ่ง)

### 1) ค่า `NFFT` และ Frequency Resolution
$$\Delta f = \frac{f_s}{\text{NFFT}}$$
* ถ้ากำหนด `NFFT` สูงขึ้นหรือใช้ Zero-Padding จะทำให้แกนความถี่ซอยยี่ละเอียดขึ้น ช่วยให้เห็นรูปทรงสเปกตรัมที่เรียบเนียนขึ้น

### 2) ทำไม $325\text{ Hz}$ ถึงแยกเป็น $320$ กับ $330\text{ Hz}$ ในกราฟช่วงแรก?
* ที่ $f_s = 16000\text{ Hz}$ และระยะเวลา $0.1\text{ วินาที}$ ($N = 1600$ จุด)
* ความกว้างช่องความถี่คือ $\Delta f = 16000 / 1600 = 10\text{ Hz}$ (0, 10, 20, ..., 310, 320, 330)
* ความถี่ $325\text{ Hz}$ ตกอยู่ **ตรงกลางระหว่างช่อง 320 กับ 330 พอดีเป๊ะ** พลังงานจึงกระจายออกข้างๆ ทำให้เกิดปรากฏการณ์ **Spectral Leakage**

### 3) ทำไมห้ามใช้ `np.argsort()` กับเสียงคนพูดจริง?
* เสียงคนพูดไม่ใช่ Sine wave จุดเดียว แต่เป็นแถบเนินพลังงานกว้างตามสรีระคอหอย (Formants $F_1, F_2, F_3$)
* ถ้าใช้ `argsort` ดิบๆ จะได้แค่ bin เสี้ยนสัญญาณที่อยู่ติดกัน (เช่น 250.1, 250.2 Hz)
* **วิธีที่ถูกต้อง:** ต้องทำ **Smoothing (Savitzky-Golay)** เพื่อเอาเสี้ยนออก แล้วใช้ **Dynamic Threshold (% of Max)** ร่วมกับ `find_peaks` จึงจะได้ Formants ที่แท้จริง

## ⚔️ 5. มวยเอกและชุดการทดลองเปรียบเทียบครบ 4 กลุ่ม (Complete Benchmark Suite)

เราแบ่งการทดลองออกเป็น 4 เสาหลัก (4 Pillars) เพื่อพิสูจน์ให้อาจารย์เห็นอย่างเป็นวิทยาศาสตร์:

| กลุ่มที่ | ชื่อวิธีการ / อัลกอริทึม | ที่มา / คอนเซปต์ | ผลการทดลอง / สิ่งที่พบ |
| :---: | :--- | :--- | :--- |
| **1** | **Standard LMS** *(เขียนเอง)* | สมการ $w + \mu e x$ | ตัดเสียงก้องได้ในระดับหนึ่ง แต่ถ้าเสียงดังกระแทกจะหลุดลอย (Diverge) |
| **2** | **Normalized LMS (NLMS)** *(เขียนเอง - พระเอก)* | ปรับสเกลพลังงาน $\frac{\mu}{\|x\|^2 + \epsilon}$ | **ดีที่สุด!** ลู่เข้าไว นิ่ง เสถียรกับเสียงพูดที่เบา-ดังไม่คงที่ เนื้อเสียงคนพูดคงเดิม |
| **3.1** | **Butterworth Filter** *(จาก Lab W7, W9)* | Classical Frequency Cut | **สอบตก!** เจอปัญหา Spectral Overlap เสียงพูดกลายเป็นเสียงอู้อี้ในโอ่ง |
| **3.2** | **Inverse Filtering** *(จาก Lab W4, W8)* | Deconvolution $H^{-1}(z)$ | เสี่ยงตัวกรองระเบิด (Unstable) เพราะ Zero ของห้องกลายเป็น Pole หลุดนอกวงกลม |
| **3.3** | **FastICA / PCA** *(จาก Lab W11)* | Blind Source Separation | แยกไม่ออก เพราะ ICA รองรับแค่เสียงบวกกันตรงๆ แต่ห้องจริงเป็น Convolutive Reverb |
| **3.4** | **STFT Spectral Subtraction** *(จาก Lab W12)* | ลบสเปกตรัมใน Time-Frequency | **พอถูไถได้ดีสุดในแล็บ** แต่เกิดปัญหา **Musical Noise** (เสียงจ๊อกๆ ใต้น้ำแหลมๆ) |
| **4** | **Standard Library Benchmark** | ใช้ไลบรารีสากล (`padasip`) | **ไม้บรรทัดวัด:** พิสูจน์ว่า LMS/NLMS ที่เราเขียนมือเอง มีผลลัพธ์แม่นยำเทียบเท่าไลบรารีมาตรฐานโลก! |

1. **ค่า ERLE (Echo Return Loss Enhancement):**
   $$\text{ERLE} = 10 \log_{10} \left( \frac{E[d^2[n]]}{E[e^2[n]]} \right) \quad (\text{dB})$$
   * วัดว่าตัวกรองสามารถลดทอนความแรงของเสียงสะท้อนลงได้กี่เดซิเบล (ยิ่งสูงยิ่งดี)
2. **Learning Curve (Convergence Plot):**
   * กราฟ Error squared $e^2[n]$ เปรียบเทียบระหว่าง LMS vs NLMS ให้เห็นความเร็วในการปรับตัว
